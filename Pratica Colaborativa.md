# Nosso primeiro trabalho colaborativo no GitHub

## Objetivo da atividade

O objetivo desta prática foi experimentar o compartilhamento de arquivos pelo GitHub, permitindo que diferentes integrantes contribuíssem para um mesmo documento.

## Descrição da atividade

Foi criado um arquivo compartilhado para que cada integrante pudesse adicionar uma dica sobre o funcionamento do GitHub.

As alterações foram realizadas individualmente, utilizando as próprias contas dos participantes.

## Teste de revisão

Foi proposta a criação de uma branch chamada melhoria-guia para realizar uma alteração no documento.

Após a modificação, deverá ser criado um Pull Request para que outro integrante analise o conteúdo e registre um comentário.

Depois da revisão, será realizado o merge para incorporar a alteração à branch principal.

## Reflexão sobre a atividade

**1. Todos conseguiram acessar e editar o arquivo?**

O grupo deverá registrar se todos os integrantes conseguiram acessar e editar o arquivo utilizando suas próprias contas.

**2. Como as mudanças chegaram aos colegas?**

As mudanças ficaram disponíveis no repositório após serem salvas e registradas por meio de commits. Os demais integrantes puderam atualizar a página para visualizar as modificações.

**3. Como identificamos os autores das alterações?**

Por meio do histórico de commits, que apresenta o autor e as modificações realizadas.

**4. O que mudou após o merge?**

A alteração realizada na branch separada foi incorporada à branch principal do projeto.

**5. Qual problema foi resolvido?**

O processo de revisão permitiu analisar uma alteração antes de incorporá-la ao projeto, contribuindo para a organização e a qualidade do conteúdo.

## Conclusão

A prática demonstrou como o GitHub facilita o trabalho colaborativo, permitindo que diferentes pessoas contribuam para um mesmo projeto e acompanhem as alterações realizadas.
