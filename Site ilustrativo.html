2. Introdução ao Git e GitHub

GitÉ um sistema de controle de versão que acompanha as alterações realizadas nos arquivos de um projeto.
GitHubÉ uma plataforma online que hospeda repositórios e facilita o compartilhamento e a colaboração em projetos.

Diferença: o Git controla as versões dos arquivos; o GitHub oferece um espaço online para armazenar repositórios e trabalhar em equipe.

O que é um repositório?

É um espaço utilizado para armazenar e organizar os arquivos de um projeto, como documentos, códigos e imagens.

Repositório público e privado

  • Público: qualquer pessoa pode visualizar o conteúdo.
  • Privado: somente o proprietário e as pessoas autorizadas podem acessar o conteúdo.

3. Primeiros passos no GitHub

Criando uma conta

  1. Acesse github.com.
  2. Clique em Sign up e informe seu e-mail.
  3. Crie uma senha e escolha um nome de usuário.
  4. Siga as instruções para concluir o cadastro.

Criando um repositório

  1. Entre na sua conta e clique em New.
  2. Escolha um nome e escreva uma descrição para o projeto.
  3. Defina se o repositório será público ou privado.
  4. Marque Add a README file e clique em Create repository.

README e Markdown

O README apresenta as informações principais do projeto, como objetivo, participantes e organização dos arquivos.

Markdown é uma linguagem de marcação simples usada para formatar textos com títulos, listas, links e negrito.

# Título do projeto
## Subtítulo
**Texto em negrito**

- Primeiro item
- Segundo item

4. Arquivos e controle de versões

Como adicionar um arquivo?

  1. Abra o repositório.
  2. Clique em Add file.
  3. Escolha Create new file ou Upload files.
  4. Digite o nome ou selecione o arquivo que deseja enviar.
  5. Clique em Commit changes para salvar.

O que é commit?

Commit é o registro de uma alteração realizada no repositório. Ele possui uma mensagem que explica o que foi modificado.

Exemplos: Adiciona arquivo README, Atualiza cartilha e Corrige informações do projeto.

Histórico de alterações

É o registro dos commits realizados. Ele permite acompanhar as mudanças e identificar quem fez cada contribuição.

5. Colaboração no GitHub

Convidando colaboradores

  1. Acesse o repositório e clique em Settings.
  2. Procure Collaborators.
  3. Clique em Add people.
  4. Digite o nome de usuário do GitHub e envie o convite.
  5. A pessoa deverá aceitar o convite.
Cada integrante deve utilizar sua própria conta. Nunca compartilhe sua senha.

Branch, Pull Request e Merge

Branch (ramificação)Versão separada do projeto usada para desenvolver alterações sem modificar diretamente a versão principal.
Pull RequestSolicitação para revisar e propor a incorporação de alterações de uma branch em outra.
Merge (mesclagem)Processo de unir as alterações de uma branch à outra.
RevisãoAnálise das mudanças por outro integrante antes de incorporá-las ao projeto.

Etapas de colaboração

  1. Criar uma branch.
  2. Realizar as alterações necessárias.
  3. Registrar um commit.
  4. Abrir um Pull Request.
  5. Solicitar a revisão de outro integrante.
  6. Após a conferência, realizar o merge.

6. Cuidados ao compartilhar arquivos

  • Não publique senhas ou códigos de autenticação.
  • Não compartilhe tokens de acesso.
  • Evite incluir dados pessoais desnecessários.
  • Confira se o repositório é público ou privado.
  • Revise os arquivos antes de enviá-los.
  • Conceda acesso somente às pessoas necessárias.

7. Prática e desafio para o leitor

Desafio: crie seu primeiro repositório de estudos.

  1. Crie um repositório chamado estudos.
  2. Escreva um README explicando o objetivo.
  3. Adicione três assuntos que deseja aprender.
  4. Crie um arquivo chamado anotacoes.md.
  5. Escreva algumas anotações sobre um dos assuntos.
  6. Registre uma alteração com um commit claro.
  7. Compartilhe o repositório com um colega.
  8. Confira se o colega conseguiu acessar e contribuir.

8. Reflexão sobre o aprendizado

O GitHub é uma ferramenta importante para estudantes e profissionais da tecnologia, pois facilita a organização de projetos, o acompanhamento de alterações e o trabalho em equipe.

O controle de versões ajuda a acompanhar o desenvolvimento de um projeto e permite que diferentes pessoas contribuam de forma organizada. Conhecer Git e GitHub é um passo importante para quem deseja seguir carreira na área de tecnologia.
